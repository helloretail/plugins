# How to Add Newsletter Content to Klaviyo

This guide explains how to add your Hello Retail Newsletter Content snippet to [Klaviyo](https://klaviyo.com/).

> **Note:**
>
> Send no more than one newsletter per day using this method. The date is used as a unique key for product selection. Multiple sends on the same date can cause duplicate products.

### How to get your Hello Retail code snippet

**Step 1**: Log in to your Hello Retail account [here](https://my.helloretail.com/company/signin.html) and create an auto campaign for the product recommendations to include in the newsletter. (If you already created a design, skip to Step 4.)

**Step 2**: When logged in, go to: **Newsletter Content** > **Auto campaigns**.

- If you already created an "**Auto campaign config**", click "**Edit auto campaign config**".
- If you have not created an "**Auto campaign config**", follow the steps below.

__ _
(Click "Create new auto campaign config" to create a design and code snippet)_

**Step 3**: Fill out the fields. Select either **2** or **3 products** per row and the total number of products to display. (In the example config, we show three products per row and six products in total.)

_(Fill out the fields as shown)_

**Step 4:** Optionally select fixed products that will always be shown, and set a "**Recommendation strategy**" (or keep the default). Then open the "**Code snippet**" tab, select "**Klaviyo**" as the newsletter platform, and copy the **code snippet**.

__ _
(Select Klaviyo as the newsletter platform and copy the code snippet as shown)_

**Step 5**: You are now done in the Hello Retail account and ready to insert the newsletter content into your Klaviyo email template.

### How to insert the Hello Retail code snippet into Klaviyo

**Step 1**: Log in to your Klaviyo account at [https://www.klaviyo.com/login](https://www.klaviyo.com/login).

**Step 2**: In Klaviyo, go to "**Email Templates**". Click "**Edit**" next to the email template where you want to add the newsletter content.

**Step 3**: Follow the video guide below to implement the code snippet into an email template.

**Step 4:** After you add the code snippet, click "**Save & Return to Templates**" in the top right corner.

**Step 5:** Send a test email to verify the content renders correctly before sending to your recipients.

> **Note:**
>
> The Klaviyo editor does not render Hello Retail Newsletter Content. The block can appear empty in the editor because recommendations are generated per recipient at send time. Use a test send to verify.
