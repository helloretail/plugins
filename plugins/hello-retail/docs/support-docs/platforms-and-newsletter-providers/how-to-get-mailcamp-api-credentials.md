# How to Get MailCamp API Credentials

To synchronize your MailCamp email permissions, Hello Retail requires access via the MailCamp API. Create API credentials by logging in to your MailCamp account and navigating to:
**My Account -> API Details**
Enable the XML API for the user and generate an API token.
After you do this, click **Save**, then send the **XML Path**, **XML Username**, and **XML Token** to Hello Retail.
