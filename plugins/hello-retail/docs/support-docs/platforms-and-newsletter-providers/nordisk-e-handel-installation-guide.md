# Nordisk E-Handel Installation Guide

This guide explains how to set up Hello Retail on Nordisk E-Handel.

* * *

## Contact the Platform

Contact your platform provider to install the _Hello Retail plugin_ and enable conversion tracking on the checkout success page. Older versions of the integration required a Hello Retail Partner ID. This is no longer required.

* * *

## Create a Blank Page for Search Results

**The following section is only relevant for setups for a full search.**

Follow these steps to install your search results on a blank page in Nordisk E-Handel:

1. Start by logging into your Nordisk E-Handel admin account.
2. Navigate to **Sidor** > **Sidor**.
3. Choose **Add new page** _(Skapa ny sida)_.
4. Give the page a suitable address and headline, for example /searchresults.html and Sökresultat.

5. Share the URL of this new page with Hello Retail to finalize the setup of Search.

* * *
