# Manual Setup

If your platform does not have a [direct integration](https://support.helloretail.com/platforms-and-newsletter-providers/setup-of-platforms-category/), you can still implement Hello Retail. Use the [developer documentation](https://developer.helloretail.com/guides/setup/) to perform a manual setup: include the Hello Retail scripts, provide a product feed, and send required tracking events from your site. The guide lists prerequisites, data formats, and validation steps. Contact our support team if you need assistance.
