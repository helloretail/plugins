# Review Grid & Full Search

In this guide, you can read and learn about how to review and test the grid & full search that has been set up on your webshop.

* * *

## Introduction

After implementing changes on your webshop, review and test that Grid Search and Full Search render and behave as intended. Verify configuration and design before exposing it to visitors.

> **Note:**
>
> Some browsers block cross-site tracking, which can prevent the Hello Retail side panel from loading. If the panel does not appear, disable this setting for your domain.

### Notice

You can review and test via the dashboard or the side panel widget. Searches can be in either draft or live state.

* * *

## Process - Testing Grid Search

1. Start by logging into your Hello Retail account.
2. Go to your webshop on your own domain to start reviewing and testing.
3. Navigate to a product page on your website.
4. Click the Hello Retail icon on the bottom-left to open the Hello Retail side panel.
5. Navigate to the Search column.
6. Toggle the Show button for the search box you want to display.
7. Click the search bar and run several test queries. Confirm that results match the intent of the query and the correct products are returned.

* * *

## Process - Verification & Review Grid Search

1. Verify the design and colors of the grid search match the rest of the website.
2. Verify that prices are displayed consistently across the website.

3. Verify that the placement of the recommendation boxes is correct.
4. Verify that badges display correctly (for example, New, On sale).
5. If your recommendations include a Buy button, verify that it works as intended. If a product has variants, the Buy button should redirect to the master product page.
6. Verify that category links work after entering a search term.

7. Test the filters to make sure they behave correctly.

* * *

## Process - Publish & Go Live

When all the above steps have been completed for the grid search on your webshop and everything works as expected, you can publish the changes to live.

### Side Panel

1. Open the Hello Retail side panel widget.
2. Navigate to the Search column.
3. Find the search box.
4. Click the Show button to make it live.

5. If needed, click Show again to hide the search. This button toggles whether the search is shown.

### Dashboard

1. Start by logging into your Hello Retail account. In the dashboard, open the left-hand menu. Under the On-Site section, click Search to unfold the drop-down menu.
2. From the drop-down menu, click Overview.
3. Choose the search from the list.

4. In this view, change the state of the search from draft to live.

* * *

## Full Search

The full search is where all search results are shown to the visitor.

A full search can be initiated and shown by:

- Clicking the View All button inside the grid search.
- Pressing Enter inside the search bar.
- Typing an asterisk (*) and then pressing Enter inside the search bar.

* * *

## Process - Testing Full Search

1. On your website, enter a query in the search bar to trigger the full search.
2. Click the View All button inside the grid search.
3. If needed, verify the same steps from [here](review-grid-full-search.md#process-verification-review-grid-search) for the full search.
