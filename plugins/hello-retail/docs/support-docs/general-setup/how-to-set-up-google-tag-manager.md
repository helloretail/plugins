# How to Set Up Google Tag Manager

## Installing the Hello Retail JavaScript through Google Tag Manager

Google Tag Manager lets you add and manage scripts on your webshop without deploying code. Use GTM to load the Hello Retail JavaScript on all pages.

Prerequisites:
- A working GTM container installed on your site.
- Your Hello Retail JavaScript snippet from the Hello Retail platform or onboarding email.

Steps:
1. In GTM, open your container and go to Tags, then click New.
2. Select Tag Type, then choose Custom HTML.
3. Paste your Hello Retail JavaScript snippet into the HTML field.
4. Click Triggering and select All Pages.
5. Save the tag, then click Submit and Publish to deploy the container.
6. Use Preview to verify the tag fires on every page and the script loads correctly.
