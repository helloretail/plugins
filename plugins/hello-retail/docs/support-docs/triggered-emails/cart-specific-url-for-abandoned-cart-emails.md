# Cart Specific URL for Abandoned Cart Emails

This guide explains how cart-specific return URLs work for Abandoned Cart emails.

* * *

## What is a Cart Specific URL for Abandoned Cart Emails?

When Hello Retail tracks a customer's cart, your integration can provide a unique return-to-cart URL. This URL restores the exact cart so the customer can continue checkout.

If your e-commerce platform cannot generate a restore URL, the Return to cart button is not shown in the email.

* * *

## Previewing and Testing

In email previews and tests, this documentation page is used as a placeholder cart URL. For live sends, Hello Retail uses the provided cart URL. If no URL is available, the button is hidden.

For details on how to provide the cart URL, see [How to set up cart tracking](how-to-set-up-cart-tracking.md).
