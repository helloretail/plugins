# Design Overview for Triggered Emails

Triggered Emails lets you send emails to customers when predefined events occur. Email design can match your shop branding, with content provided by Hello Retail.

The design has two layers: a **base design** and **individual designs** for each trigger type (for example, Abandoned Cart). The **base design** defines the overall layout and shared styles—header, footer, button styles, typography, and other common elements—that all trigger types inherit. Each trigger then renders its specific content within this base.

The first step is to design the **base design**, followed by each individual trigger you plan to use. You can read more about the base design [here](base-design-for-triggered-emails.md).
