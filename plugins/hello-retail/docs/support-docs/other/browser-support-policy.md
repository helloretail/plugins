# Browser Support Policy

Hello Retail defines which browser versions are supported for Product Recommendations, Search, and the Dashboard (admin area). This policy enables fast, reliable development so we can release new features quickly and with minimal defects.

## Product recommendations & Search:

For Product Recommendations and Search, we support all browsers with more than 1% usage, based on W3Schools statistics ([https://www.w3schools.com/browsers/default.asp](https://www.w3schools.com/browsers/default.asp)). Older browsers may still work, but we do not guarantee full functionality or a bug-free experience.

The current support is as follows:

**Desktop browsers:**

- Any current version of Google Chrome, Mozilla Firefox, Apple Safari, or Microsoft Edge

**Mobile browsers:**

- Any current version of Mozilla Firefox, Apple Safari, or Google Chrome

## Dashboard (Admin area)

The Dashboard uses progressive web technologies. The following browsers are supported and recommended for the Dashboard:

**Desktop Browsers:**

- Google Chrome: Latest 2 versions
- Mozilla Firefox: Latest 2 versions
- Apple Safari: Latest 2 versions
- Microsoft Edge: Latest 2 versions

If you have questions about browser support, please [contact us](mailto:support@helloretail.com).
