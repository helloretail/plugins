# How To Add Fixed Products - in Product Recommendations

In this guide, you can read and learn about how to add fixed products for your recommendation boxes on your webshop.

If you want to learn about fixed products for search, check out this guide [here](../search/fixed-and-removed-products-in-search.md).

If needed, you can also check out this guide about product lookup [here](../general-setup/product-lookup.md).

* * *

This video guide shows how to force specific recommendations to show certain products, that are not otherwise chosen by the algorithms. See the listed steps below for a textual explanation of how this is achieved.

#### Prerequisites

- Make sure that Hello Retail has already been set up correctly on your webshop.
- Start by logging into your Hello Retail account.

## Steps - How to add the fixed products:

1. Find the product or products on your webshop that you want to add to a recommendation box.
2. On the product page, open the Hello Retail widget in the bottom left corner and click it.
3. Click on **Page Details** inside the widget.
4. Copy the URL from **Page Details**.
5. Go to the page on your webshop that contains the recommendation box where you want to add the fixed product. For this example, it will be on the front page.
6. Click on **Product Boxes** inside the widget and select the specific recommendation box where you want to add the fixed product. For the example, we are adding it to the box called **Anbefalet til dig** (Recommended for you).
7. Click the **Edit fixed products** button in the selected recommendation box.
8. Click the **Add fixed product** button.
9. Paste the product URL you copied earlier into the field.
10. Click **Save**. The product is added to the recommendation box on that page and will appear immediately.
